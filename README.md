# YouTube Thumbnail Downloader & Metadata Extractor

Скрипт автоматизации для выгрузки обложек (thumbnails) и очищенных метаданных из последних видео произвольного YouTube-канала. Скрипт создаёт готовую рабочую среду для последующего контент-анализа или скармливания контекста ИИ-агентам (LLM).

Генерирует файлы, полностью совместимые с базой знаний **Obsidian**.

## Особенности

- **Очистка от спама:** Автоматически вырезает из описания видео ссылки, рекламу, упоминания соцсетей (Discord, Patreon, Telegram, Instagram и т.д.).
- **Obsidian-ready:** Формирует валидный YAML Frontmatter в файле `info.md`, который корректно парсится Obsidian. Ссылки на картинки подставляются автоматически во внутреннем формате вики-ссылок `![[01_file.webp]]`.
- **Динамический формат изображений:** Автоматически определяет реальное расширение скачанной обложки (`.webp`, `.jpg`), предотвращая битые ссылки в markdown.
- **Промпт для ИИ-агента:** Создаёт готовый файл `analysis-prompt.md` на русском языке, который можно скопировать и отправить ИИ (ChatGPT, Claude, Gemini) для детального разбора визуала и CTR-стратегии канала.
- **Интеграция с Node.js:** Корректно настраивает рантайм для `yt-dlp`, предотвращая появление системных предупреждений (Warnings) в консоли.

## Структура проекта

```text
YT-crawler-bot/
├── download_thumbnails.py   # Основной Python скрипт
├── run.ps1                  # Скрипт запуска для PowerShell (Windows)
├── run.bat                  # Скрипт запуска для классической командной строки
└── <channel_name>_thumbnails/ # Выходная папка (создается автоматически)
    ├── 01_name.webp
    ├── 02_name.webp
    ├── info.md              # Метаданные и структурированные описания
    └── analysis-prompt.md   # Готовый промпт для ИИ-агента

```

### Системные требования

    Python 3.8+

    Node.js (опционально, рекомендуется для быстрой расшифровки подписей yt-dlp).

### Использование
Способ 1: Использование PowerShell (Рекомендуемый для Windows)

Запустите скрипт через PowerShell. Он автоматически развернет виртуальное окружение venv, обновит yt-dlp и запустит парсер:
PowerShell

.\run.ps1 "[https://www.youtube.com/@perepolox/videos](https://www.youtube.com/@perepolox/videos)"

Если скрипт запущен без аргументов, он запросит ссылку интерактивно прямо в консоли.
Способ 2: Прямой запуск из терминала

Если вы работаете в активированном окружении:
Bash

python download_thumbnails.py "[https://www.youtube.com/@ИМЯ_КАНАЛА/videos](https://www.youtube.com/@ИМЯ_КАНАЛА/videos)" 12

Где 12 — количество видео для парсинга (по умолчанию скачивается 12).
Разбор выходных файлов в Obsidian

    Скопируйте сгенерированную папку <channel_name>_thumbnails в ваш Obsidian Vault.

    Откройте info.md. Вы увидите структурированные карточки по каждому видео, включая таблицы метаданных, очищенный текст описания от автора и отображение локальных картинок внутри заметок.

    Откройте analysis-prompt.md, скопируйте его содержимое и используйте в диалоге со своим ИИ-ассистентом для маркетингового разбора канала.
